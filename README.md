# 💻 Dev Career Tracker

## ✨ Возможности

* **🎯 Калибровка стартового грейда**
  Входной тест на 20 вопросов разной сложности + учет прошлых коммерческих проектов автоматически определяют твой текущий уровень (`Trainee`, `Junior`, `Junior+`, `Middle`, `Senior`) и засчитывают стартовые часы.
* **⏱ Точный таймер и журнал сессий**
    * Раздельный учет времени: **Коммерция** и **Учеба / Пет-проекты**.
    * Таймер не сбивается при сворачивании вкладки или перезагрузке страницы.
    * Возможность вносить время вручную и просматривать историю по дням.
* **💰 Финансы и реальная ставка (₽/ч)**
    * Учет разовых **Заказов** и полноценных **Проектов** (в прогресс грейда идут только проекты).
    * Автоматический расчет реальной стоимости часа на основе коммерческих сессий.
    * Фильтрация дохода за месяц, год или всё время + сводка по прошлым месяцам.
* **🎓 Система грейдов и экзамены**
    * Для перехода на следующий уровень нужно набрать необходимое количество часов практики, закрыть нужное число проектов и сдать экзамен (минимум 80% правильных ответов).
* **🗺️ Карта навыков (Roadmap) и планировщик задач**
    * Интерактивный чек-лист навыков под каждый грейд, который автоматически дополняется при повышении уровня, плюс возможность добавлять свои темы.
    * Список задач с поддержкой подзадач и прогресс-барами.
* **🏆 Геймификация (32 достижения)**
    * Ачивки за часы за кодом, количество заказов, закрытые проекты, финансовые цели и рост почасовой ставки.
* **🔒 Приватность и бэкапы**
    * Все данные хранятся локально в `localStorage` браузера — никакой регистрации и внешних серверов. Встроенный экспорт и импорт прогресса в JSON.
